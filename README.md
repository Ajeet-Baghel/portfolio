# portfolio

Personal portfolio of Ajeet Baghel — React 19 + TypeScript + Vite + Tailwind CSS v4 + GSAP + Three.js.

See [PLAN.md](PLAN.md) for the build roadmap and design direction.

## Development

```bash
npm install
npm run dev      # start dev server
npm run build    # typecheck + production build
npm run preview  # preview production build
```

## Deployment

Deployed on Vercel.
